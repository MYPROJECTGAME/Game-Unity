# Game-Unity

Granny horror game (Unity 2020.2). Open Assets/Scenes/Main.unity and press Play.
WASD move, Shift sprint, Mouse look, E doors, R restart.

The game uses the supplied reference art from Assets/Resources: GoldenKey.png for all ten collectibles, WoodFloor.png for the house floor, and GhostWoman.png for the pursuing ghost.
